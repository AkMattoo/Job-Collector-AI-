How it works

  1. CollectGitHub Actions runs a Python job daily. It pulls public JSON from Greenhouse, Lever and Ashby boards.
  2. NormalizeThree API shapes become one schema, so nothing downstream knows which board a job came from.
  3. FilterTitle, location and posting-age rules drop most postings before any AI call. Cheap work first.
  4. ScoreSurvivors go to Gemini in batches with a strict JSON schema: fit score, reason, tailored resume bullets.
  5. StoreA job is recorded only after it's scored, so a failed AI call means a retry tomorrow, never a silently lost job.
  6. ServeResults are committed as JSON and served statically. The chat is a serverless agent with a search tool over that data.

Signals like posted and still open are measured from the boards. The model is never asked to guess things it can't know, like pay a posting doesn't state or a company's culture.
